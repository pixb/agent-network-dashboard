## 6. 已知不足以夸口的地方

- 所有自动化证据来自**夹具数据 + headless 浏览器**，不等同于真实登录、真实网络规模。
- 3D 的 canvas 内文字不走 DOM 对比度审计，靠 `data-node-text-alpha` 与截图守护。
- 触摸手势覆盖旋转/缩放/平移/滑动，未覆盖长按等更复杂手势。
- 真实规模（数百节点）下的帧率只有 dense 夹具（13 部门/42 Agent）的测量。
