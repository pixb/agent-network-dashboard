## 4. 不可自动化判断的部分（明确边界）

- `rounded-md` 在某些「输入框内联按钮」上可能是刻意的小圆角，机械替换会改变控件辨识度；
- `text-[9px]` 在状态点/角标里承担「极小徽标」语义，直接放大可能撑破卡片；
- 因此每一批都必须**截图比对**，不接受「数量归零」作为完成标准。
